Source de courant constante — Montage Kelvin 4 fils

Corrosion Monitor M2 — ESP32 + HX711 + LM358 + Transistor NPN (2N2222 / BC547 / S8050)

Cible : I = 50 mA constant dans le fil ER. Mesure de tension Kelvin (sans erreur de contact).

Comment lire ce schema

  • Rouge gras = boucle de COURANT (50 mA passe par la)
  • Bleu = boucle de TENSION sense (aucun courant - HX711)
  • Vert = boucle de REGULATION (feedback LM358)
  • Pointilles rouges = alimentation VCC des chips
  • Pointilles noirs = retour GND des chips
  • Boites "V_E" = noeuds avec le meme nom -> relies par un fil unique

Boucle de courant (en ROUGE)

VCC (3.3V) -> point B -> fil ER -> point A -> collecteur NPN -> emetteur NPN -> R_cal (10) -> GND

Le courant I = 50 mA est force constant par le LM358. Peu importe si la resistance du fil change (corrosion), le courant reste exactement a 50 mA.

Boucle de mesure de tension (en BLEU)

HX711 A+ <- point D --- fil ER --- point C -> HX711 A-

Les points D et C sont des contacts sense : aucun courant ne passe (impedance HX711 = 10 M). Donc la chute de tension dans les contacts D et C est nulle - la tension lue est exactement V(D) - V(C), soit la tension aux bornes des 80 cm de fil entre D et C.

Boucle de regulation (LM358 - en VERT)

Le LM358 lit V_emetteur sur pin 2, compare a V_REF (trim pot) sur pin 3, ajuste sa sortie pin 1 pour ouvrir/fermer le NPN jusqu'a ce que V_E = V_REF. C'est ce qui rend le courant constant.

SEQUENCE DE MISE EN ROUTE - A RESPECTER STRICTEMENT
  1. Cabler TOUT sans alimenter
  2. Verifier au multimetre : continuite sur les wires VCC et GND, pas de court-circuit entre VCC et GND
  3. Tourner le trim pot pour V_REF = 0 V - mesurer wiper vs GND au multimetre avant alim
  4. Alimenter en 3.3V (idealement alim labo regulee, PAS l'ESP32 d'abord)
  5. Mesurer tension aux bornes de R_cal : doit etre environ 0 V (transistor bloque)
  6. Tourner DOUCEMENT le trim pot jusqu'a lire 0.5 V aux bornes de R_cal (= 50 mA dans le fil)
  7. Toucher du doigt : NPN, R_cal, fil. Si chaud (> 50C) -> STOP, retour etape 3
  8. Brancher le HX711 sur D et C
  9. Brancher l'ESP32 et demarrer la mesure
Position physique des 4 contacts sur le fil immerge (100 cm)
  • B = a 5 cm du haut du bain (juste sous la surface du HCl)
  • D = a 15 cm (10 cm sous B)
  • C = a 95 cm (10 cm au-dessus de A)
  • A = a 105 cm (a 5 cm du fond du bain)

Tu mesures la resistance des 80 cm de fil immerge entre D et C. C'est la zone attaquee par le HCl dont la section diminue (R augmente).

Adaptation firmware Arduino

Le code actuel calcule R via le pont Wheatstone. Avec Kelvin, le calcul devient trivial :

// Constantes Kelvin (remplace tout le bloc pont Wheatstone)
const double I_CONSTANT_A = 0.050;     // 50 mA - a calibrer au multimetre
const double V_REF_HX711  = 4.2987;    // AVDD du HX711 mesure

double lire_resistance() {
  unsigned long t0 = millis();
  while (!scale.is_ready() && millis() - t0 < 3000) delay(10);
  if (!scale.is_ready()) return last_Rx;

  long reading = scale.read_average(MESURES_PAR_CYCLE);
  double v_sense = (double)reading * V_REF_HX711 / (128.0 * 8388608.0);

  // Loi d'Ohm directe - pas de pont, pas de ratio
  double Rx = v_sense / I_CONSTANT_A;

  if (Rx < 0.01 || Rx > 100.0) return last_Rx;  // garde-fou
  return Rx;
}
